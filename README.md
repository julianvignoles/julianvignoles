# Hi, I'm Julian

I'm a senior in the Biotechnology Institute at Carlmont High School in Belmont, California, and an Eagle Scout. I build tools with Claude Code, mostly things I wanted to exist and couldn't find.

## Projects

- **[claim-check](https://github.com/julianvignoles/claim-check)**: a Claude skill that audits writing claim by claim and reports only what is wrong, unverified, or opinion presented as fact.
- **[ask-the-council](https://github.com/julianvignoles/ask-the-council)**: a Claude skill that runs a decision through six perspectives built to disagree, then gives one clear recommendation.
- **[marketplace-watcher](https://github.com/julianvignoles/marketplace-watcher)**: a self-hosted Facebook Marketplace wishlist watcher built with Next.js and Playwright.
